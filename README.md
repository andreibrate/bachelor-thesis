# Bachelor Thesis Prototype

This repository contains the Python prototype developed for my bachelor thesis:
**From A to C: A Practical Comparison of Associational and Causal Inference Methods Across Multiple Domains**

The prototype compares purely associational analyses with simple DAG-based causal analyses across four case studies involving confounding, collider/selection bias, observational data, and hiring fairness.

## Case Studies

1. **Synthetic Treatment Case**
   - Causal concept: Confounding and Simpson's paradox
   - Exposure: Treatment
   - Outcome: Recovery
   - Confounder: Disease severity

2. **Synthetic Esports Case**
   - Causal concept: Collider and selection bias
   - Exposure: Practice
   - Outcome: Performance
   - Selection variable: Tournament qualification
   - Additional variable: Baseline skill

3. **ESS Health Case**
   - Dataset: European Social Survey Round 11, Austria
   - Causal concept: Confounding in observational data
   - Exposure: Physical activity
   - Outcome: Subjective health
   - Assumed confounders: Age, gender, and education

4. **GEMM Hiring Case**
   - Dataset: GEMM Study
   - Application: Gender and hiring outcomes
   - Exposure: Applicant gender
   - Outcome: Employer invitation

## Requirements

The prototype was developed and tested using:

- Python 3.11.9
- NumPy 2.3.3
- pandas 2.3.2
- Matplotlib 3.10.6
- DoWhy 0.14

The Python package dependencies are listed in `requirements.txt`.

## Installation

Create and activate a Python virtual environment, then install the required packages:

```bash
pip install -r requirements.txt
```

A Jupyter-compatible environment is required to execute the notebooks.

## Running the Prototype

The four case studies can be executed independently from the `notebooks` directory.

For the intended order, run:

```text
01_synthetic_treatment.ipynb
02_synthetic_esports.ipynb
03_ess_health.ipynb
04_gemm_hiring.ipynb
```

Each notebook contains the preprocessing steps, associational analysis, causal model or adjustment strategy, effect estimation, evaluation, and interpretation for the respective case study.

## Reproducibility

Fixed random seeds are used for the synthetic data-generating processes. All four analysis notebooks were tested by restarting their kernels, clearing previous outputs, and executing all cells from beginning to end.

The synthetic cases additionally include sensitivity analyses that vary the strength of confounding and selection. The real-world cases include robustness or specification checks appropriate to their respective study designs.

## Data

The prototype uses two synthetic and two real-world datasets.

The synthetic datasets are generated by the notebooks contained in their respective `data/raw` directories.

The real-world datasets are:

- **European Social Survey Round 11, Edition 4.2** for the physical-activity and subjective-health case.
- **GEMM Study: A Cross-National Harmonized Field Experiment on Hiring Discrimination** for the hiring case.

Further information about dataset selection, preprocessing, causal assumptions, and interpretation is provided in the bachelor thesis.

## Important Note

The prototype is intended as an educational and analytical demonstration rather than a general-purpose causal inference application. In particular, causal estimates from observational data depend on the causal assumptions represented by the specified DAGs and should not be interpreted as definitive proof of causal relationships.
